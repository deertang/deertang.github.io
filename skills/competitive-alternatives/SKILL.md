# 竞争与替代分析

## 目标
系统识别竞争与替代方案，判断行业结构与可进入空间。

## 关键输入
- 目标用户与核心任务
- 产品/方案的价值主张
- 可获得的市场与竞品信息

## 核心流程（建议 3-6 步）
1. 明确用户要完成的任务与价值衡量标准
2. 划分竞争类型：直接竞争、替代方案、潜在进入者
3. 用五力框架评估行业结构与利润分配
4. 评估差异化空间（价值、成本、渠道、体验、商业模式）
5. 输出竞争地图、机会与风险假设

## 判断方法
- 竞争不仅是“同类产品”，也包括替代方案
- 行业结构决定利润空间，需关注买方/供方议价与进入壁垒
- 差异化应建立在可持续的优势来源上

## 输出格式
- 竞争/替代矩阵
- 五力评估表（1-5 分）
- 机会与威胁清单
- 初步策略假设

## 常见坑
- 只看同类竞品，忽略替代方案
- 只比功能，不比较商业模式与分发渠道
- 忽视进入壁垒与反击能力
